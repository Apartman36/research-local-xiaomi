# Research Task: AI Interior Design and 3D Apartment Visualization

Research current AI tools and implementation approaches for apartment interior design, 3D room visualization, room redesign from photos, floorplan-to-3D workflows, furniture placement, and realistic interior rendering.

Focus on:
1. Existing commercial tools.
2. GitHub or open-source projects if available.
3. Technical approaches: image-to-image, inpainting, ControlNet, segmentation, 3D reconstruction, world models, Three.js/WebGL/Blender pipelines.
4. What can realistically be built by one developer as an MVP.
5. Main risks: geometry accuracy, furniture scale, copyright, privacy, API cost, and output quality.

Final report should be practical and implementation-oriented.
