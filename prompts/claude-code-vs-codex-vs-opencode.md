# Research Task: Claude Code vs Codex vs OpenCode — What Is Better and When?

Compare Claude Code, OpenAI Codex, and OpenCode for a developer who uses AI coding agents heavily.

The goal is to understand when each tool is best, what their strengths and weaknesses are, and how they can be combined in one workflow.

Focus on:

1. Official capabilities and positioning
   - Claude Code
   - OpenAI Codex / Codex CLI / ChatGPT coding workflows
   - OpenCode

2. Best use cases
   - large codebase refactoring
   - greenfield app generation
   - debugging
   - test writing
   - code review
   - research-driven implementation
   - CLI automation
   - multi-agent workflows
   - local/private workflows

3. Tool architecture
   - CLI behavior
   - agent model
   - tool permissions
   - file editing
   - terminal usage
   - MCP / plugins / custom tools
   - model/provider flexibility

4. Practical comparison
   - speed
   - reliability
   - autonomy
   - safety
   - cost / token usage
   - Windows support
   - WSL support
   - GitHub integration
   - local project ergonomics

5. Combination strategy
   - Codex as implementation brain
   - Claude Code as reviewer / tester / large-context critic
   - OpenCode as local tool/search/sub-agent runtime
   - Xiaomi MiMo as cheap/high-volume reasoning/search assistant through OpenCode

6. Risks and limitations
   - hallucinated edits
   - bad shell commands
   - weak test coverage
   - context loss
   - tool permission risks
   - API/provider lock-in
   - unstable docs or fast-changing behavior

7. Recommended workflow
   - for small scripts
   - for large TypeScript/Node projects
   - for AI research tools like research-local-xiaomi
   - for one-evening MVP building
   - for production hardening

Prefer:
- official docs
- GitHub repositories
- changelogs
- credible technical articles
- recent public discussions if available

Important:
- Mark uncertain claims clearly.
- Do not overclaim current capabilities.
- Compare tools practically, not as marketing.
- Produce a decision matrix.
- Produce a final recommendation for how this project should use all three tools.
- Report language: English.
