# Research Task: Open-Source AI Interior Design and Room Visualization Projects

Find open-source GitHub repositories, technical demos, papers with code, and implementation references for AI interior design, room redesign, floorplan-to-3D, furniture placement, and image-conditioned room generation.

Focus on:
1. GitHub repositories.
2. README quality.
3. Architecture and implementation details.
4. Models/libraries used.
5. Whether each project is maintained.
6. Whether it can be reused by one developer for an MVP.

Final report should rank the most useful implementation references and explain why.
